Any questions?

Things teams ask before they switch

Is Brindle really open-source?

Yes. The core is published under a permissive licence, you can read every line, and you can run it on your own servers.

How long does it take to get started?

Most teams have a first schema and real records in under an hour with the local setup, and a shared workspace by the end of the day.

Can I migrate from my current CRM?

Yes. Import maps your existing objects and fields, and an agent can draft the mapping for you to review before anything is written.

Do I need a developer to customize Brindle?

Not for everyday changes: objects, fields and views are point and click. A developer helps when you want custom logic.

Can developers extend Brindle with code?

Yes. Blocks are plain TypeScript, tested and deployed like the rest of your software.

Does Brindle work with the coding agents I use?

It ships a schema and command reference that agents read directly, so they can propose changes you review as ordinary diffs.

What does Brindle cost?

Self-hosting is free. Hosted workspaces are priced per seat, with a flat rate for read-only users.
